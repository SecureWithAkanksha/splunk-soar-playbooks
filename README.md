
# 🔐 Splunk SOAR Playbooks

Security automation scripts and playbooks for SOC operations — built for phishing triage, malware containment, and automated alert enrichment using Splunk SOAR + Python.

---

## 🛠️ Tools & Technologies
- **SOAR:** Splunk SOAR (Phantom)
- **Language:** Python 3
- **Integrations:** VirusTotal, AbuseIPDB, ServiceNow
- **Concepts:** Alert Enrichment, Incident Triage, REST APIs, Error Handling

---

## 📁 Scripts

| File | Description |
|------|-------------|
| `virustotal_lookup.py` | Query VirusTotal API for IP reputation and malicious verdict |
| `abuseipdb_check.py` | Check AbuseIPDB for IP abuse confidence score |
| `servicenow_ticket.py` | Auto-create ServiceNow incident tickets from SOAR alerts |
